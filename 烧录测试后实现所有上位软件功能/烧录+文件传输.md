# 烧录 + 文件传输

[官方网站](https://no-chicken.com/content/Echo-Mate/4.%E9%95%9C%E5%83%8F%E7%83%A7%E5%BD%95.html)
> 本节需要按开发板上的 **BOOT** 键。

## 烧录（NAND）

1. 打开瑞芯微 SocToolKit，选择 RV1106
2. 按住 BOOT 键 → USB 插上电脑 → 松开 BOOT，出现 Maskrom
3. 选择 NAND 固件（`update.img`），点击下载

> SD 卡作为启动介质需先擦除 NAND Flash，否则默认从 NAND 启动。

- 之前在 [烧录测试](../硬件+上位软件测试/烧录测试.md) 提到的github issues bug修复可以通过编译Demo根治,想做的自己去看github issues

## SCP bin 文件

烧录完成后：

```bash
scp -r DeskBot_demo/bin/* root@172.32.0.93:/root/bin/
```
