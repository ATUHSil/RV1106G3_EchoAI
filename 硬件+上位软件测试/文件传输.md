# 文件传输

> 自行 SCP 官方的bin 文件到开发板，实现从零搭建完整功能环境。

## 前提

- [底层测试](底层测试.md) 全部通过
- [上位软件测试](上位软件测试.md) 全部通过
- 已完成 SDK 编译和 Demo ARM 交叉编译（编译产物在 `DeskBot_demo/bin/`）

## 1. SCP bin 到板子

```bash
# 从电脑传输 bin 目录下所有文件到板子
scp -r DeskBot_demo/bin/* root@172.32.0.93:/root/bin/
```

## 2. 验证

重新执行 [底层测试](底层测试.md) 和 [上位软件测试](上位软件测试.md)，确认所有功能正常：

| 测试 | 说明 |
|------|------|
| SSH 登录 | 能登录 |
| WiFi | ping 通 |
| 屏幕 | UI 正常，花屏/清屏有反应 |
| 音频 | 播放和录音正常 |
| 天气/时间 | 准确显示 |
| AI 聊天 | 正常对话 |
