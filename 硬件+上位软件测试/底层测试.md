# 底层测试


[官方教程](https://no-chicken.com/content/Echo-Mate/5.%E5%BC%80%E5%8F%91%E6%9D%BF%E6%93%8D%E4%BD%9C.html#_1-%E5%BC%80%E5%8F%91%E6%9D%BF%E8%BF%9E%E6%8E%A5%E4%B8%8E%E7%99%BB%E5%BD%95)
- 注意不要用串口登陆而要使用ssh登录,串口登录易损坏开发板
- 搭配官方教程和我下面的教程使用
- 本节完成除了需要api key才能使用的聊天app和天气时间以外的正常功能和硬件的测试
- 注意开发板已默认将官网的Echo-Mate桌面机器人可执行文件bin和相应配置设置好 ，在从未进行过当前的测试并改动在做什么不要在scp bin也就是直接做下面的不用管什么事scp bin

## 1. 硬件组装

严格遵循 [防止损坏](../硬件+上位软件测试/防止损坏.md)前提下：

- 插屏幕排线 + 屏幕
- 插音响
- 插 WiFi 天线

全部为插拔式，无需焊接。

## 2. SSH 登录
要下载MobaXterm:https://mobaxterm.mobatek.net/ 

USB 连接板子后，设置电脑端 RNDIS 网卡 IP 为 `172.32.0.100`（子网掩码 `255.255.255.0`）。
官方b站有视频教程
打开MobaXterm通过ssh连接开发板(注意不要通过ch340串口连接)
```bash
#或者直接终端连接
ssh root@172.32.0.93
# 密码: root
```

ssh连接开发板后
```bash
cd /root/bin
./main
```

> 必须从 `/root/bin` 目录运行，程序依赖相对路径 `./gaode_adcode.json` 等资源文件。

正常现象：LVGL UI 启动，显示主界面。大多数app如计算器，绘画等可以使用
需要配置API key才能使用的聊天app和天气时间等，未配置无法使用


## 3. WiFi 连接

```bash
ifconfig wlan0 up

# 先加载 WiFi 驱动（已预装）
/oem/usr/ko/insmod_wifi.sh

# 配置 WiFi
vi /etc/wpa_supplicant.conf
```

`/etc/wpa_supplicant.conf` 内容：

```
ctrl_interface=/var/run/wpa_supplicant
update_config=1

network={
        ssid="WiFi名"
        psk="密码"
        key_mgmt=WPA-PSK
}
```

```bash
mkdir -p /var/run/wpa_supplicant
wpa_supplicant -B -c /etc/wpa_supplicant.conf -i wlan0
wpa_cli status       # 确认 wpa_state=COMPLETED
udhcpc -i wlan0
ping baidu.com       # 通 = 正常
```

> 切换 WiFi 前先 `killall -9 wpa_supplicant`。

## 4. 文件传输
注意可以这里的scp就是开头说的SCP Bin的scp，可以传输普通文件但不要传输bin文件

```bash
# 从电脑传文件到板子
scp 文件路径 root@172.32.0.93:/root/

# 传文件夹
scp -r 文件夹路径 root@172.32.0.93:/root/
```

## 5. 屏幕测试

```bash
# 调背光（0~49）
echo 49 > /sys/class/backlight/backlight/brightness

# 花屏测试
cat /dev/urandom > /dev/fb0

# 清屏
cat /dev/zero > /dev/fb0
```

## 6. 音频测试

```bash
# 加载驱动
/oem/usr/ko/insmod_ko.sh

# 确认声卡
aplay -l    # card 0: rvacodec
```

### 播放

```bash
amixer -c 0 cset name='DAC LINEOUT Volume' 30
speaker-test -t sine -f 1000 -c 1 -l 5 &   # 听到"嘟"声 = 正常
sleep 3 && killall speaker-test
```

### 录音

```bash
# 差分麦克风，必须 DiffadcL
amixer -c 0 cset name='ADC Mode' 'DiffadcL'
amixer -c 0 cset name='ADC Digital Left Volume' 255
amixer -c 0 cset name='ALC ALC Left' 'Off'
amixer -c 0 cset name='ALC AGC Left' 'Off'

arecord -f S16_LE -d 5 -r 16000 -c 1 /tmp/test.wav
aplay /tmp/test.wav    # 听到录制的声音 = 正常
```
