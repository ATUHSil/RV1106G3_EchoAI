# 上位软件测试

> 底层测试通过后，配置 API key 使能聊天、天气/时间等功能。

[官网](https://no-chicken.com/content/Echo-Mate/6.%E8%BF%90%E8%A1%8C%E6%A1%8C%E9%9D%A2%E6%9C%BA%E5%99%A8%E4%BA%BA.html)

## 前提

- [底层测试](../硬件+上位软件测试/底层测试.md) 全部通过
- 已申请阿里云百炼 API Key 和高德地图 API Key
- 板子 WiFi 已连接

## 1. 配置 system_para.conf

板子上编辑 `/root/bin/system_para.conf`：

| 参数 | 值 |
|------|-----|
| `server_url` | 电脑在 WiFi 下的 IP（和板子同网段） |
| `port` | `8000` |
| `protocol_version` | `2` |
| `access_token` | 和 Server 端一致，如 `123456` |
| `aliyun_api_key` | 阿里云百炼 `sk-xxxx` |
| `amap_apikey` | 高德地图 API Key |
| `auto_time` | `true`（自动 NTP 同步） |

> WiFi 连接后 `ifconfig wlan0` 可看到板子 IP。电脑 IP 需在同一网段（如手机热点，电脑也连同一热点）。

## 2. 启动 AI Chat Server

在电脑端（WSL2 Docker 内或本地 Python 环境）：

**! 注意**
官网资料链接的Echo-Mate桌面机器人可执行文件bin 可能为旧文件，如果是旧文件则存在bug导致无法使用AI Chat Server（具体见[github issue 9](https://github.com/No-Chicken/Demo4Echo/issues/9)）

```bash
cd Echo-Mate/Demo/AIChat_demo/Server

# 安装依赖（仅首次）
python -m venv venv && source venv/bin/activate
pip install torchaudio==2.3.0 --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --timeout 120 --retries 10
```


下面是按照其为旧文件的快速修复(无需编译demo)的方案
修改两个文件
**文件 1**: `AIChat_demo/Server/config/settings.py`
```python
import dashscope

class Settings:
    protocol_version = 2
    # 使用你自己 API Key
    dashscope.api_key = "sk-ws-自己的api key"

    # 模型选择
    INTENT_MODEL = "qwen-turbo"       # 专门用于意图识别
    CHAT_MODEL = "qwen-turbo"         # 用于常规对话

    ASR_DEVICE = "cpu"
    VAD_DEVICE = "cpu"
    API_TIMEOUT = 10

    def Set_API_Key(self, aliyun_api_key):
        dashscope.api_key = aliyun_api_key

global_settings = Settings()
```

**文件 2**: `AIChat_demo/Server/handle/text_handler.py`

```diff
              api_key = data.get('api_key', None)
-            global_settings.Set_API_Key(api_key)
+            # 不覆盖服务端配置的 API Key，始终使用 settings.py 中的 key
+            # global_settings.Set_API_Key(api_key)
```

然后重启服务器即可：

```bash
cd /project/Demo/AIChat_demo/Server
source venv/bin/activate
python ./main.py --access_token="123456"
```

看到 `Server started on port 8000` 表示启动成功。

## 3. 启动板子端

```bash
cd /root/bin
./main
```
