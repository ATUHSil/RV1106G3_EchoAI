# 开发环境对比及测试



## 开发环境对比

| 环境 | 上手难度 | 网上搭建教程量 | 资源占用 |
|------|----------|----------------|----------|
| VMware 虚拟机 | 低 | 多 | 高 |
| WSL2 | 中 | 多 | 中 |
| WSL2 + Docker | 高 | 少 | 中 |


## 我的开发环境
我的开发环境为 **WSL2 Arch Linux + Docker**（Luckfox Pico 官方镜像 `luckfoxtech/luckfox_pico:1.0`）。
搭建和测试过程: [wsl+docker](wsl+docker.md)  ( Ai 总结过程，未二次验证， 部分可能存在问题，自行矫正)

根据你个人情况选择开发环境,不想花时间搭环境+新手 =>  VMware虚拟机，b站搭建视频多
如果选择WSL2不如直接按照我的过程用WSL2+docker
